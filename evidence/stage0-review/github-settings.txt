Conclusion:
- main is NOT protected: the public branch metadata reports "protected": false and
  "protection.enabled": false.
- There are NO repository rulesets: the rulesets endpoint returns an empty list.
- Required status checks are therefore NOT enabled. They are part of branch protection or a
  ruleset, and neither exists.
- CODEOWNERS does not exist on main (HTTP 404). The A4 branch has CODEOWNERS, but GitHub
  does not enforce it on main until the file lands on the base branch and review is required.
- D-031 / XB-012 remain Open. The A4 Stage 0 merge gate is advisory until the Director
  enables protection, required checks and a base-branch CODEOWNERS file.
