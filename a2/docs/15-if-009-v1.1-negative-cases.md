## Scope

A1 accepted IF-009 v1.0 with two explicit gaps: truncated PE headers and a missing DLL name in an
import descriptor. This page records the six negative cases that close those gaps at evidence level
L0. A pass means the parser rejected the malformed image for the named reason. It does not mean the
image was loaded or executed.
